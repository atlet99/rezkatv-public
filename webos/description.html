RezkaTV

RezkaTV — это современный медиа-клиент для потокового воспроизведения контента на телевизорах LG webOS. Мы создали приложение, которое объединяет в себе простоту использования и мощный функционал для комфортного просмотра.

Выберите вашу версию

У нас есть две версии приложения, оптимизированные для разных поколений телевизоров:

Рекомендуется

RezkaTV Modern

Полнофункциональная версия на Vue 3 с современным интерфейсом.

  • Полный функционал
  • Современный UI
  • Высокая производительность

  • Профиль и синхронизация

webOS 5.x - 24.x (2020-2024)

RezkaTV Legacy

Оптимизированная версия на Vanilla JS для старых телевизоров.

  • Легковесная (~100KB)
  • Базовый функционал
  • Оптимизирована для слабых CPU
  • Минимальное потребление RAM
  • ES5 совместимость

Как определить версию webOS?

  1. Нажмите кнопку Settings на пульте
  2. Перейдите в General → About This TV
  3. Найдите строку webOS TV Version
    • Версия 3.x или 4.x → выберите Legacy
    • Версия 5.x и выше → выберите Modern

Установка через Homebrew Channel

  1. Установите Homebrew Channel на ваш телевизор
  2. Откройте Homebrew Channel
  3. Добавьте репозиторий: https://atlet99.github.io/rezkatv-public/webos/repository.json
  4. Найдите RezkaTV или RezkaTV Legacy
  5. Нажмите Install
